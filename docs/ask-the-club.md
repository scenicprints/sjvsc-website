# What the club has to be asked

Written 16 Nov 2026.

The 2027 calendar sheet gives names and dates. The Oct–Dec 2026 newsletter covers
only the events up to the end of this year. The old Network Solutions site has more
than either, but it is a year or two out of date and is not trusted as a source.

So everything below is a gap no document answers. It is written to be forwarded
whole: whoever puts the newsletter together will know most of it, and the officers
will know the rest between them.

Events are listed in the order they happen.

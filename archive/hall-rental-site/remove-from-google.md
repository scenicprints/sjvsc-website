# Getting the dead rental site out of Google

The site returns 404 at every address, but Google still lists it, which is
how it was found in the first place. A 404 drops out of the index on its
own eventually — "eventually" being weeks to months, during which anyone
searching for the hall is sent to a dead page.

It can be hurried. Google's **Remove Outdated Content** tool exists for
exactly this: a page that is gone but still listed. It does not need
ownership of the site, because the proof is the 404 itself — Google checks
the address, sees nothing there, and drops it.

  https://search.google.com/search-console/remove-outdated-content

Sign in with any Google account, press **New Request**, paste one address,
submit. Repeat. Requests are usually actioned within a few days.

## The part that matters more

Removing the old listing stops people landing on a dead page. It does not
put anything in its place.

The old Network Solutions site was built so that the HTML carried a title
and nothing else, which is why the club has been close to invisible in
search for years. The new site is plain HTML and can be read, but it went
up on 13 November 2026 and Google has barely looked at it yet.

So the rental page outranking the dead one is a matter of Google
re-crawling, not of anything that needs building. Submitting the new site
at https://search.google.com/search-console — which does need ownership of
the domain, and the club has that now — is what shortens the wait.
